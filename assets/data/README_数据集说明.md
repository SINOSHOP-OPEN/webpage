## 一、机理：一个物理过程，三个功能

```text
潮位升降 → 吃水变化 → 组合墙浸没面积变化 → 净浮力失衡 ΔF
                                              │
                    潮汐发电水舱（柱内/墙内，与压载水舱物理分离）
                                              │
      ① 液位随外部水面自然起落 —— 零耗能（无泵、无外力）
      ② 液位差顺流驱动涡轮 —— 顺流发电，非强迫
      ③ 排水/蓄水抵消 ΔF ⇒ 浮体高度恒定
```

> **关键**：①③ 是同一件事的两面 —— 浮力要变，水舱就补/放，
> 恰好顺流而下即为发电。**这就是「零耗能」的物理来源。**
