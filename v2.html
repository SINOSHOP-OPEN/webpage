第一章 项目概述

1.1 项目定位与目标

本项目基于发明专利 CN110534176B《一种大数据智能防病养生应用系统》，建设以智慧马桶为核心终端的健康数据平台，实现无感采集、智能分析与个性化养生方案推送。核心目标是建立个人健康动态数据库，探索用户共享健康数据的数字资产权益机制。

全流程闭环：智慧马桶采集 → 边缘端S1-S4预处理 → 云端加密分析 → S5-S8方案匹配 → 养生方案推送 → 用户反馈/医生审核 → 算法迭代 → 脱敏数据集生成 → 数据产品入表 → 用户权益返还。

本期聚焦"智慧马桶健康数据接入"，涵盖数据采集、云端分析、方案推送三大环节，同步建立数据产品体系、用户权益体系与开放生态架构。

1.2 开发模式

采用AI智能体主导开发 + 人工程序员审核修正双层模式：

层级 角色 职责
代码生成层 AI智能体 负责80%以上基础代码编写
审核修正层 程序员白福栋（手机端，兼职） 移动端代码审核与修正
审核修正层 程序员周彬（后台端，兼职） 后台端代码审核与修正

核心安全模块（零信任、数据脱敏、区块链存证）由人工程序员深度复审。

1.4 建设约束

（1）范围约束：一期（0-6个月）完成核心平台建设；穿戴设备接入、数据产品交易等作为能力预留，分阶段实施。

（2）知识产权声明：专利由丁方梁振雄、戊方盛兵共同持有，已授权本项目使用，授权期限为项目存续期。智慧马桶方投入不改变专利归属。项目交付须提供专利授权/许可协议副本。

（3）合规红线：严格遵循《数据安全法》《个人信息保护法》《网络数据安全管理条例》（2025年1月1日起施行）及《数据出境安全评估办法》，坚守"原始数据不出域、数据可用不可见"原则。L3级数据加密存储，L2级数据脱敏后分析。第三方接入须经用户明示授权并签订DPA。

（4）数据主体权利：用户可随时撤回授权、删除数据。撤回后云端数据72小时内彻底删除，审计日志留存≥3年。用户同时享有数据资产权益（详见第六章）。

（5）全域非医疗声明：本系统不属于医疗器械，不具备疾病诊断、治疗、预防功能。所有输出页面永久水印："非医疗诊断数据，仅作养生趋势参考"。禁用词清单：诊断、治疗、预防疾病、治愈等。审核记录留存≥3年。

（6）极端工况约束：断网、断电、传感失效、第三方API下线。RPO=0，网关RTO≤30s，本地缓存断点续传。

第三章 数据采集标准与合规红线

3.1 核心采集字段（最小必要集）

  • L3级：体温、血压、血糖、尿酸、呼吸率、脉搏；尿pH、比重、蛋白、潜血；中医体质辨识结果；用户自报病症
  • L2级：起床/睡眠时间、睡眠时长、工作劳累度、身体感觉、天气感知

3.2 数据分级与保护

级别 范围 保护措施
L3体征、体质、病症加密存储+传输，绑定设备元档案ID
L2起居作息、脱敏衍生数据集脱敏后分析，授权访问
L1设备运行数据、匿名统计基础保护

3.3 合规红线

  • 知情同意：伦理审查 + PIA评估 + 电子授权+纸质知情书双留存
  • 最小必要：仅采集防病养生直接相关字段
  • 数据不出域：原始数据本地加密，云端仅接收脱敏特征值
  • 可追溯：全访问审计日志，设备关键事件哈希凭证
  • 出境限制：健康数据原则上不出境，跨境须安全评估+单独同意

数据主体权利：映射表→删除流水线→72h全节点删除→审计凭证；JSON/CSV导出，日志留存≥3年；独立合规角色抽查删除效果。

公共数据池：未识别数据留存≤90天，自动粉碎；剥离设备ID/时间戳/网络指纹；禁止参与AI训练。

第五章 防病养生大数据分析引擎

5.1 核心算法S1-S8（权利要求10，详见附录三）

S1-S2 时间序列加权：倒序斐波数列加权（1,1,2,3,5,8,13...），近期高权重、远期指数衰减。

S3-S4 环境调节系数：环境指标对健康信息影响系数修正。扩展体质偏移差值子模块，输出偏移量作为纠偏输入。

S5-S8 无量纲化概率匹配：方案矩阵无量纲化→概率匹配→选取Fj最大值方案。

算法版本管理：V[主].[次].[修订]；每次变更记录前后快照、原因、审批人、生效时间；月度审计日志。
